# PAT Basic Level Practice by C

PAT Basic Level（乙级）题目练习仓库，使用 C 语言记录题解与代码实现说明。

## 在线阅读

本仓库已配置为 Docsify 静态站点，可通过 GitHub Pages 在线浏览。打开左侧导航即可查看全部 125 道题解，也可以使用搜索框按题号或关键词检索。

Pages 启用并完成首次 Actions 部署后，站点地址为：

```text
https://pta-program.github.io/pta_basic_level_practice_by_c/
```

页面提供以下功能：

- 左侧导航覆盖全部题解；
- 题号和关键词搜索；
- 上一题 / 下一题导航；
- C 代码复制、图片缩放与 Mermaid 流程图渲染；
- 页面右下角亮色 / 暗黑模式切换，并记住用户选择。

首次启用时，请在 GitHub 打开 `Settings` → `Pages`，将 `Build and deployment` 的 `Source` 设为 `GitHub Actions`，然后推送到 `main` 或 `master` 分支，或手动运行 `Deploy Docsify to GitHub Pages` 工作流。

## 本地预览

在仓库根目录运行：

```bash
python3 -m http.server 8899 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8899/>。Docsify 依赖 CDN 加载主题和插件，首次打开页面需要网络连接。

## 仓库内容

- 覆盖题号 **1001–1125**，当前共 **125** 道题目。
- 每道题目的 Markdown 题解文件直接存放在根目录，文件名格式为 `题号-题目名称.md`；代码实现、原理、步骤和注释均写在文档的“代码实现”部分。
- `images/`：集中存放部分题目说明所引用的图片资源。

## 目录示例

```text
1001-害死人不偿命的(3n+1)猜想.md
images/
└── *.jpg
```

直接打开对应的 Markdown 文件查看题目说明、实现原理、实现步骤、代码注释和流程图。不同题目的输入输出要求不同，请以对应 Markdown 文件中的说明为准。
